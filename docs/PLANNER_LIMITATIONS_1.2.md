# CORE OS 1.2 — Planner Known Limitations

This foundation does not infer capabilities from natural-language objectives, query live provider health, rank providers by latency/quality/risk, reserve resources, dynamically replan after execution failures, learn from historical outcomes, or orchestrate real external mutations.

Provider descriptors used at planning time are declarations supplied in the request envelope. Their live truth is not attested by this change. These limitations are deliberate boundaries for the first capability-graph foundation.
